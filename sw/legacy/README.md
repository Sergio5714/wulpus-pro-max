# Legacy notebooks

This directory contains older specialized WULPUS PRO notebooks retained for
reference and reproducibility:

- `wulpus_pro_gui.ipynb`
- `wulpus_pro_gui_tgc.ipynb`
- `wulpus_pro_cmuts_gui.ipynb`
- `wulpus_pro_env.ipynb`

For current USB CDC, Wi-Fi, or BLE operation, use
[`../wulpus_pro_example.ipynb`](../wulpus_pro_example.ipynb). The legacy
notebooks may depend on older APIs and are not maintained as the primary usage
path.
