# Transducers

WULPUS Pro Max supports piezoelectric (PZT) and capacitive micromachined
ultrasonic (CMUT) transducers. When bringing up a new system, we recommend
starting with a simple single-channel transducer before connecting a more
complex array.

## Recommended starting point

For preliminary testing, use the following low-cost single-channel transducer:

- **DYW-LS-03A** (2 or more)
  — [order from AliExpress](https://de.aliexpress.com/i/1005006042868528.html?gatewayAdapt=glo2deu)

Using a single-channel transducer makes it easier to verify basic transmit and
receive operation before moving to a multi-channel transducer or array.

## Additional components

The following components are required to connect transducers to the WULPUS Pro
Max acquisition board:

| Component | Part number | Recommended quantity | Supplier |
| --- | --- | ---: | --- |
| 16-position connector | DF52-16P-0.8C | 2 or more | [DigiKey](https://www.digikey.ch/de/products/detail/hirose-electric-co-ltd/DF52-16P-0-8C/5721348) |
| Pre-crimped wire | DF52-2832PF1571-28A9-300 | 32 or more | [DigiKey](https://www.digikey.ch/de/products/detail/hirose-electric-co-ltd/DF52-2832PF1571-28A9-300/11204482) |

!!! note

    Confirm the connector orientation and acquisition-board channel mapping
    before assembling the cable. Do not connect or disconnect a transducer
    while the system is transmitting.
